## Objective

Deliver OPERATOR_ADMIN trip cancellation and alternative-route disruption with Booking pending actions. Cancellation is allowed only for SCHEDULED or BOARDING. Payment refunds only from booking.booking.cancelled.

## Contract changes

POST /v1/operator/trips/{id}/cancel/preview has empty body and 200 data {tripId,status,affectedBookingIds,refundTotal}. POST /v1/operator/trips/{id}/cancel has empty body plus UUID-v4 Idempotency-Key and 200 data {tripId,status}. POST /v1/operator/trips/{id}/change-route has exactly {alternativeRouteId} plus UUID-v4 Idempotency-Key and 200 data {tripId,status,alternativeRouteId,affectedBookingIds}. Errors: 404 TRIP_NOT_FOUND or ROUTE_NOT_FOUND; 409 TRIP_NOT_EDITABLE. Sources: BE_TIMELINE_VU.md Day 33; API Contract Trip edit and AlternativeRoute sections; BSOT 5.6, 5.9, 6, 7; technical_context_v7 6.4, 6.5, 6.12; trip schema/README.

`npm run postman:full:local`; it calls `scripts/run-full-e2e-local.mjs` and exercises the
Gateway at `http://localhost:3000` for every public request. Harness-only fixture setup and
post-run inspection are local verification seams, not application request paths.

an external reviewer needs no hidden fixture state. VNPay coverage is a signed local-IPN simulation,
not a real bank transaction or merchant-sandbox integration.

harness owns deterministic fixture setup, short-lived generated test JWTs, and `try/finally`
cleanup in reverse dependency order. JWTs and secrets must never be printed in full.

## Runner gates and exclusions

`run-full-e2e-local.mjs` treats D11-D19 as required stages in dependency order. Before it starts
Docker, it checks every listed harness exists. A missing harness, a failed invocation, or an
unapproved skip exits non-zero. D12 and D16 are implemented required stages; they run only through
their named harnesses and may not be replaced by another happy path.

### Task 20.1 evidence-led D16 mode correction

D16 now runs the documented local signed-VNPay IPN simulation against real Booking, Trip, and
Payment seams. Concrete booking/IPN/poll/refund evidence established that the previous Booking
dev-stub matrix mode could not prove the required payment boundary. The harness snapshots the
pre-run Booking mode and restores it in `finally`, including after a forced Newman failure. This
is an evidence-led runner-only correction: no public contract, application source, schema, or
dependency changed.

Required verification is `node scripts/run-day16-newman-local.mjs` plus
`DAY16_FORCE_NEWMAN_FAILURE=true node scripts/run-day16-newman-local.mjs`; each must emit its
fixture-cleanup and mode-restore `PASS` lines.

No Sprint 3 stage has an approved exclusion. A future exclusion must name the stage, reason,
source-of-truth/timeline citation, and human approval, and the runner must emit an explicit
`SKIP | DNN | <approved reason>` line. Google OAuth is outside this Sprint-3 matrix; its existing
external-credential skip is therefore not an exclusion for any D11-D19 stage.
